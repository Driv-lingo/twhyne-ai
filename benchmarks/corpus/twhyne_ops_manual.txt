Section 2.1 - Deployment.
The Twhyne appliance runs as a single Docker container on facility-managed
hardware. The web frontend is served on port 3000 and the backend API on
port 5002. The first launch performs a one-time model download of
approximately 13 GB into the operator's home directory.

Section 2.4 - Network Posture.
The system operates fully offline. The only outbound internet call the
system makes is license validation against the licensing server at startup.
No resident data, documents, or queries ever leave the facility network.

Section 3.2 - Maintenance and Backups.
Nightly backups of the knowledge-base storage run at 02:00 local time.
Backups are retained for 30 days and then purged automatically. Software
updates are applied by re-running the launcher, which pulls the newest
container version; models and knowledge bases are preserved across updates.

Section 4.1 - Incident Escalation.
Suspected malfunctions or data issues must be escalated by notifying the
facility IT administrator, who will collect the container logs and contact
vendor support if required. Do not attempt manual edits to the knowledge
base storage while an incident is open.
